# 💾 Banco de Dados I – IFSP Araraquara

Repositório dedicado à disciplina **Banco de Dados I** do curso de Tecnologia em Sistemas para Internet do **Instituto Federal de Educação, Ciência e Tecnologia de São Paulo – Campus Araraquara**.

## 📚 Ementa da Disciplina

A disciplina tem como foco os fundamentos de banco de dados relacionais, envolvendo:

- Conceitos básicos de banco de dados;
- Modelagem de dados com o modelo entidade-relacionamento (MER);
- Projeto lógico e físico de banco de dados;
- Linguagem SQL (Data Definition Language – DDL e Data Manipulation Language – DML);
- Introdução à normalização de dados;
- Fundamentos de sistemas de gerenciamento de banco de dados (SGBDs).

## 🎯 Objetivos

### Geral
Proporcionar aos alunos o entendimento sobre o funcionamento, a modelagem e o uso de bancos de dados relacionais, com foco em aplicações reais no desenvolvimento de sistemas.

### Específicos
- Compreender o papel de um banco de dados em sistemas de informação;
- Dominar técnicas de modelagem de dados (conceitual e lógica);
- Executar comandos SQL para definição e manipulação de dados;
- Aplicar princípios básicos de normalização;
- Entender a estrutura e o funcionamento de um SGBD.

## 🧠 Conteúdos Abordados

- Conceitos iniciais de banco de dados e SGBDs;
- Modelagem conceitual com MER;
- Transformação para modelo relacional;
- Projeto físico de banco de dados;
- Normalização (1FN, 2FN, 3FN);
- Comandos SQL (SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER, DROP);
- Estudos de caso e projetos práticos.
